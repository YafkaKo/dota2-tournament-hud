# HUD трансляции Dota 2

Оверлей для студенческого турнира: графика поверх игры, заставки, турнирная сетка,
итоги карты, вероятность победы и пульты, с которых всё это переключается прямо в эфире.

Работает на ваших компьютерах в локальной сети. Без аккаунтов и подписок.
Интернет нужен только для иконок героев (серверы Valve) и для догрузки итогов
карты из OpenDota — без него всё работает, просто без этих двух вещей.

---

## Как это устроено

```
   Dota 2 (клиент наблюдателя)
        │  ~10 раз в секунду шлёт состояние матча
        ▼
   http://<ПК с сервером>:3000/gsi
        │
   Сервер (Node.js) ─── склеивает снимок матча, замораживает итоги,
        │               считает вероятность победы, после карты спрашивает OpenDota
        │
        ├──► overlay.html      → OBS, источник «Браузер»
        ├──► control.html      → пульт оператора (все сцены)
        ├──► /control          → пульт для телефона (сцены, плашки, счёт, тексты)
        └──◄ agent/            → агент хоткеев на ПК с Dota: сцены OBS + плашки HUD
```

Данные из игры берутся через **Game State Integration** — штатную функцию Dota 2.
Клиент, который *играет* матч, отдаёт данные только по своему герою. Клиент, который
**наблюдает** матч, отдаёт данные по всем десяти игрокам. Поэтому нужен отдельный
компьютер или хотя бы отдельный аккаунт наблюдателя.

## Что нужно один раз настроить

### 1. Node.js

Node.js 18 или новее с nodejs.org (LTS). Проверка: `node -v` в командной строке.

### 2. Запуск сервера

Двойной клик по **start.bat**. При первом запуске он сам поставит зависимости.
В окне появятся адреса, в том числе для других ПК в сети:

```
Оверлей для OBS      http://localhost:3000/overlay.html?obs=1
Пульт оператора      http://localhost:3000/control.html
Пульт для телефона   http://localhost:3000/control
С других ПК в сети   http://192.168.1.10:3000/control
```

Окно должно быть открыто весь эфир. При первом запуске Windows спросит про
брандмауэр — разрешите доступ в **частных** сетях, иначе пульт комментатора
и агент хоткеев с других ПК не достучатся.

### 3. Подключение Dota 2

Скопируйте `config/gamestate_integration_arena.cfg` в папку:

```
...\Steam\steamapps\common\dota 2 beta\game\dota\cfg\gamestate_integration\
```

Папки `gamestate_integration` может не быть — создайте её сами.

В Steam: правый клик по Dota 2 → Свойства → Параметры запуска → `-gamestateintegration`.
Перезапустите игру.

Пример конфига (он же лежит в `config/`):

```
"Arena Tournament HUD"
{
    "uri"       "http://localhost:3000/gsi"
    "timeout"   "5.0"
    "buffer"    "0.1"
    "throttle"  "0.1"
    "heartbeat" "10.0"
    "data"
    {
        "provider"  "1"
        "map"       "1"
        "player"    "1"
        "hero"      "1"
        "abilities" "1"
        "items"     "1"
        "draft"     "1"
        "buildings" "1"
        "wearables" "0"
    }
    "auth"
    {
        "token" "arena-hud"
    }
}
```

Если Dota и сервер на разных ПК — в `uri` впишите IP компьютера с сервером.
Порт и токен должны совпадать с `config/server.json`.

### 4. OBS

Источник **Браузер**:

| Поле | Значение |
|---|---|
| URL | `http://localhost:3000/overlay.html?obs=1` |
| Ширина × высота | 1920 × 1080 |
| Пользовательский CSS | оставить только `body { background-color: rgba(0,0,0,0) }` или очистить |
| Выключать источник, когда не виден | снять галочку |
| Обновлять при активации сцены | снять галочку |

Источник с игрой кладите **под** браузер-источник.

### 5. Агент хоткеев (по желанию)

Нужен, если сцены OBS хочется переключать прямо из игры, а OBS стоит на другом ПК.
Настройка — в разделе «Хоткеи прямо из игры» ниже.

## Как этим пользоваться

### Пульт оператора — `control.html`

Все сцены, названия команд, счёт серии, заставки, сетка, Trivia. Изменения уходят
в эфир мгновенно и переживают перезапуск сервера.

| Кнопка | Что в эфире |
|---|---|
| **Игра** | графика поверх игры; во время драфта сама показывает экран пиков и банов |
| **Скоро начнём** | заставка с заголовком и обратным отсчётом |
| **Перерыв** | заставка перерыва |
| **Сетка** | турнирная сетка |
| **Итог карты (заставка)** | крупная надпись с победителем и счётом серии, вручную |
| **Таблица счёта (живая)** | все десять игроков прямо из игры |
| **Чистый экран** | только картинка игры |

Хоткеи пульта (работают, пока вкладка в фокусе и курсор не в текстовом поле):

| Хоткей | Действие |
|---|---|
| `Alt+1` … `Alt+6` | сцены по порядку кнопок |
| `Alt+T` | Trivia |
| `Alt+P` | вероятность победы |
| `Alt+R` | итоги карты |

### Пульт для телефона — `/control`

Открывается с любого телефона, планшета или ноутбука в той же сети:
`http://<IP сервера>:3000/control` (IP сервер пишет в своём окне при запуске).
Права у всех одинаковые: комментатор, режиссёр и оператор видят одно и то же,
любое нажатие сразу уходит в эфир и на все открытые пульты.

Сверху всегда видно, что сейчас в эфире, игровое время и проценты. Внизу четыре вкладки:

| Вкладка | Что там |
|---|---|
| **Эфир** | все сцены HUD крупными кнопками, вероятность победы, итоги карты |
| **Плашки** | вся графика, полоса золота, Рошан, составы, комментаторы, Trivia; кнопка «Убрать все плашки» |
| **Матч** | названия команд, счёт серии ±, формат, смена сторон, стадия, «Сбросить матч» |
| **Тексты** | Trivia с заготовками, имена комментаторов, обратный отсчёт в одно нажатие (5/10/15 мин), текст перерыва, бегущая строка |

**Заготовки Trivia.** Напишите факт заранее и нажмите «В заготовки». Во время паузы
достаточно нажать «Вывести» у нужной заготовки — она сразу в эфире. Заготовки хранятся
на сервере, их видно со всех устройств.

**Как значок на экране телефона.** В браузере телефона: меню → «Добавить на главный
экран». Пульт будет открываться как отдельное приложение, без адресной строки.

На ноутбуке с широким экраном вкладки не нужны — все разделы видны сразу.
С клавиатуры работают `Alt+P` (вероятность) и `Alt+R` (итоги).

Что важно знать:
- Пульт работает только в локальной сети и без пароля: открыть его может любой,
  кто подключён к той же Wi-Fi. Если сеть общая для зрителей, раздайте отдельную.
- Экран телефона может гаснуть во время эфира — увеличьте время блокировки
  в настройках телефона на время трансляции.
- Если связь пропала, наверху появится красная полоса, пульт переподключится сам.

### Итоги карты

Когда карта заканчивается (стадия `POST_GAME` или в данных появился победитель),
сервер **замораживает** последний полный снимок и сам выводит плашку итогов:
победитель, счёт по убийствам, длительность и по каждому игроку — герой, уровень,
K/D/A, нетворс, GPM/XPM, ластхиты/денаи, урон по героям и строениям, предметы.

Плашка держится, пока её не скроют или пока не начнётся новая карта (сменится
`matchid`). Итоги сохраняются в `data/match.json`, так что и перезапуск сервера
их не теряет. Если включить плашку до конца карты, она покажет текущую статистику
с подписью «Карта идёт».

Сразу после окончания сервер начинает спрашивать OpenDota: матч там появляется
с задержкой, поэтому попытки идут с нарастающими паузами (настраиваются в
`config/server.json`). Что пришло — дописывается в пустые поля, без пустых ячеек:
колонка, по которой нет данных ни у кого, просто не показывается. Статус виден
на пульте комментатора. Матчи из закрытых лобби могут в OpenDota не появиться
вовсе — тогда остаются данные из игры, это нормально.

Автопоказ итогов можно выключить: `"results": { "autoShow": false }`.

### Вероятность победы

Считается на сервере по данным из игры: разница золота, опыта, живых строений
и убийств. Чем дальше в игру, тем меньше весит та же разница в золоте и опыте.
Результат зажат в 3–97%: в доте камбэки случаются.

**Это эвристическая оценка, а не предсказание Dota Plus** и не обученная модель.
Коэффициенты подобраны вручную и лежат в `config/probability.json`:

```json
{
  "bias": 0,
  "netWorth":   { "weight": 0.18, "per": 1000, "timeScaleMin": 20 },
  "experience": { "weight": 0.10, "per": 1000, "timeScaleMin": 20 },
  "buildings":  { "weight": 0.12, "towerValue": 1, "barracksValue": 2 },
  "kills":      { "weight": 0.03, "timeScaleMin": 20 },
  "clamp":      { "min": 3, "max": 97 }
}
```

Файл можно править на ходу — сервер перечитает его сам. Разбивка, сколько дал
каждый признак, видна по адресу `/api/match`. Ориентиры при нынешних значениях:
5k золота на 10-й минуте — около 65%, 15k на 30-й при разнице в опыте и башнях —
около 85–90%.

### Сравнение «было → стало»

Каждый раз, когда комментатор включает плашку, сервер запоминает игровое время и
процент. Если среди прошлых включений этой карты есть сделанное **5 и более игровых
минут** назад, под плашкой появляется строка:

```
10:00 → 25:30   ИТ-факультет 42% → 58%   ▲16
```

Берётся самое свежее из подходящих включений. Время считается по игровым часам —
паузы не входят. Если подходящего снимка нет, строки нет. Порог — в
`config/server.json`, `"comparison": { "minAgeSec": 300 }`. Новая карта стирает снимки.

Если хочется, чтобы сравнение было доступно, даже когда плашку давно не включали,
задайте `"autoSnapshotEverySec": 300` — сервер будет сам делать снимок каждые
5 игровых минут.

## Хоткеи прямо из игры (агент)

Папка `agent/` — отдельная маленькая программа для ПК, где запущена Dota. Она слушает
клавиатуру даже когда игра в фокусе и:

- переключает сцены OBS через obs-websocket (OBS может стоять на другом ПК);
- включает и выключает плашки вероятности и итогов через сервер HUD.

Нажатия не перехватываются — игра их тоже получает, поэтому сочетания взяты такие,
которые Dota не использует.

### Настройка

1. В OBS: Инструменты → Настройки сервера WebSocket → включить, порт `4455`,
   задать пароль. Кнопка «Показать сведения о подключении» покажет IP.
2. Скопируйте папку `agent/` на ПК с Dota (если это другой компьютер) и откройте
   `agent/config.json`:

```json
{
  "obs": { "url": "ws://192.168.1.20:4455", "password": "пароль из OBS" },
  "hud": { "url": "http://192.168.1.10:3000" },
  "reconnect": { "minSec": 1, "maxSec": 15 },
  "hotkeys": [
    { "keys": "Ctrl+Alt+F1", "scene": "Игра" },
    { "keys": "Ctrl+Alt+F2", "scene": "Драфт" },
    { "keys": "Ctrl+Alt+F3", "scene": "Камера комментаторов" },
    { "keys": "Ctrl+Alt+F4", "scene": "Повтор" },
    { "keys": "Ctrl+Alt+F5", "scene": "Перерыв" },
    { "keys": "Ctrl+Alt+F6", "scene": "Скоро начнём" },
    { "keys": "Ctrl+Alt+F7", "scene": "Сетка" },
    { "keys": "Ctrl+Alt+F8", "scene": "Итоги" },
    { "keys": "Ctrl+Alt+F9",  "hud": "probability" },
    { "keys": "Ctrl+Alt+F10", "hud": "mapResults" }
  ]
}
```

3. Запустите **agent/list-scenes.bat** — он покажет точные имена сцен вашего OBS.
   Скопируйте их в `scene` один в один, с регистром и пробелами.
4. Запустите **agent/start-agent.bat**. В окне будет список хоткеев и строка
   «OBS подключён». Окно можно свернуть.

Агент сам переподключается, если OBS перезапустили или пропала сеть, и пишет
в окно, что происходит: какие сцены переключены, каких сцен нет в OBS, недоступен
ли сервер HUD.

### Если хоткеи не срабатывают в игре

- Запустите Dota в режиме **«Окно без рамки»** (Настройки → Видео → Режим отображения).
  В эксклюзивном полноэкранном режиме глобальные хоткеи на части систем не доходят.
- Агент и Dota должны работать с одинаковыми правами: если Dota запущена от
  администратора, агента тоже запускайте от администратора — иначе Windows
  не отдаёт ему нажатия.
- Сочетание может перехватывать драйвер видеокарты (у Intel бывают Ctrl+Alt+F12
  и Ctrl+Alt+стрелки) — поменяйте его в `config.json`.

### Если Dota и OBS на одном ПК

Агент не обязателен: в OBS есть свои глобальные хоткеи (Настройки → Горячие клавиши
→ «Переключиться на сцену»). Они тоже работают при игре в фокусе, если Dota в режиме
«Окно без рамки». Агент тогда нужен только для плашек HUD — или включайте их
с пульта комментатора.

### Проверка без OBS и без клавиатуры

```
npm run mock:obs                                   (в папке проекта: имитатор OBS)
node agent.js --list-scenes                        (в папке agent)
node agent.js --simulate "Ctrl+Alt+F3"             выполнить хоткей без нажатия
node agent.js --no-hook                            только держать связь с OBS
```

## Что игра отдаёт наблюдателю, а что нет

| Данные | Откуда |
|---|---|
| счёт, время, стадия, победитель, matchid, пауза | GSI, `map` |
| K/D/A, нетворс, GPM/XPM, ластхиты/денаи | GSI, `player` |
| герой, уровень, жив ли | GSI, `hero` |
| предметы и нейтралка | GSI, `items` |
| строения обеих сторон | GSI, `buildings` (наблюдателю — по обеим) |
| урон по героям и строениям, лечение | в GSI наблюдателя есть не всегда → OpenDota |
| суммарный опыт героя | поле `hero.xp` есть не во всех версиях клиента → иначе считаем как XPM × время |
| официальная вероятность Dota Plus | в GSI её нет → своя оценка (см. выше) |

Сервер ничего не выдумывает: если поля нет, колонка скрывается, а модель
вероятности пропускает признак. Что реально пришло, видно в `/api/state`.

## Как всё протестировать

### Без Dota 2 — имитатор

Запустите сервер, затем **start-test-data.bat** и выберите режим:

| Режим | Что проверяет |
|---|---|
| 1 — матч в разгаре | графика поверх игры, вероятность |
| 2 — драфт | экран пиков и банов |
| 3 — конец карты | итоги: 15 с игры, затем `POST_GAME`, затем урезанные пакеты, как после выхода наблюдателя в меню |
| 4 — быстрая игра ×10 с паузами | сравнение вероятности за 5+ минут, исключение пауз |
| 5 — другой matchid | сброс итогов при новой карте |

Те же режимы из командной строки: `npm run mock`, `npm run mock:end`,
`npm run mock:fast`, `node tools/mock-gsi.js --match=7900000002`.
Дополнительно: `--winner=dire`, `--no-damage` (без урона в данных — проверить догрузку из OpenDota).

### Чек-лист ручной проверки

**Конец игры → итоги**
- [ ] Режим 3. Через ~15 секунд в оверлее сама появляется плашка «Победа …»
- [ ] Ещё через 7 секунд имитатор шлёт пустые пакеты — плашка остаётся с теми же цифрами
- [ ] Открыть оверлей в новой вкладке — итоги видны сразу
- [ ] Перезапустить сервер — итоги на месте (`/api/health` → `"resultsFrozen": true`)
- [ ] На пульте комментатора снять «Итоги карты» — плашка плавно уходит; включить — возвращается
- [ ] Режим 5 (другой matchid) — итоги сбрасываются, галочка «Итоги карты» снимается сама

**Вероятность: включение и выключение**
- [ ] Режим 1. На пульте комментатора включить «Вероятность победы» — плашка выезжает за ~0,4 с
- [ ] Проценты меняются плавно, сумма всегда 100
- [ ] Галочка совпадает на двух открытых пультах и после перезагрузки страницы
- [ ] Выключить — плашка плавно уходит

**Сравнение через 5+ минут**
- [ ] Режим 4. Включить вероятность, выключить
- [ ] Подождать около минуты (это 5+ игровых минут; паузы имитатора не считаются), включить снова —
      под плашкой строка «мм:сс → мм:сс … ▲/▼N»
- [ ] Выключить и сразу включить — сравнение остаётся с тем же исходным снимком,
      пока не появится более свежий снимок старше 5 минут
- [ ] «Сбросить матч» — после него при включении строки сравнения нет

**Пульт с телефона**
- [ ] Телефон в той же Wi-Fi, открыть `http://<IP сервера>:3000/control` — обе точки сверху зелёные
- [ ] Нажать «Перерыв» — в оверлее заставка, на втором открытом пульте кнопка тоже подсвечена
- [ ] Сохранить две заготовки Trivia, вывести одну — плашка в эфире, заготовка помечена «В эфире»
- [ ] «Убрать все плашки» — в эфире осталась только верхняя лента
- [ ] Выключить сервер — на телефоне красная полоса; включить — пульт переподключился сам

**Хоткеи сцен**
- [ ] `npm run mock:obs` в одном окне, в `agent/config.json` адрес `ws://127.0.0.1:4455`
- [ ] `node agent.js --simulate "Ctrl+Alt+F3"` — в окне имитатора «→ сцена «Камера комментаторов»»
- [ ] С настоящим OBS: запустить агента, в игре нажать `Ctrl+Alt+F1…F8` — сцены переключаются
- [ ] Закрыть OBS — агент пишет «связь потеряна» и пробует снова; открыть — «OBS подключён»
- [ ] `Ctrl+Alt+F9` / `F10` — плашки HUD появляются и уходят

### С Dota 2 — одиночный тест

1. Запустите сервер.
2. Лобби: **зрители — вкл**, боты, старт.
3. Зайдите **как наблюдатель**.
4. На пульте загорится зелёный кружок «игра».
5. Доиграйте или сдайте карту — должны появиться итоги.

### Диагностика

- `/api/health` — идут ли данные, номер матча, заморожены ли итоги
- `/api/state` — склеенный снимок из игры целиком
- `/api/match` — вероятность с разбивкой по признакам, снимки, статус OpenDota

Открыть `/gsi` в браузере нельзя — увидите `Cannot GET /gsi`. Это нормально:
туда принимаются только POST-запросы от игры.

## Если не работает

**В окне `start.bat` мусор вроде `'?авлю' is not recognized…`.** Баг `cmd.exe` с
кириллицей внутри блоков `if (...)`. Батники проекта написаны без таких блоков;
если правили их сами — проверьте это первым. Обходной путь: в `cmd` в папке
проекта ввести `npm install`, затем `node server\index.js`.

**Итоги не появились после конца карты.**
- Наблюдатель вышел из матча раньше, чем игра перешла в `POST_GAME`, и данных
  о победителе так и не пришло. Включите «Итоги карты» вручную — покажется
  последний полученный снимок со статистикой (без победителя). Чтобы не попадать
  в эту ситуацию, наблюдателю не выходить из матча до экрана итогов.
- `"autoShow": false` в `config/server.json`.

**Плашка вероятности не появляется.** До горна она не показывается, после конца
карты — тоже. Проверьте, что в `/api/match` есть `probability`.

**Оверлей в OBS чёрный.** Нужен источник «Браузер» с URL, а не захват окна.

**Кружок «игра» не горит.**
- Клиент играет, а не наблюдает.
- Нет параметра запуска `-gamestateintegration`.
- `.cfg` не в той папке или назван не `gamestate_integration_*.cfg`.
- Порт или токен в `.cfg` не совпадают с `config/server.json`.
- Брандмауэр блокирует порт 3000.

**Пульт комментатора не открывается с другого ПК.** Брандмауэр Windows на ПК с
сервером: разрешите Node.js в частных сетях, сеть должна быть помечена как частная.

**Иконки героев пустые.** Нужен интернет (серверы Valve). На месте иконок будет
фирменная подложка — эфир не сломается.
