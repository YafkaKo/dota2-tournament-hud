# Arena 5×5: кастомка Dota 2 для турнира по локальной сети

Это обычная Dota 5×5 на стандартной карте `dota`. Матч хостится на компьютере в арене, поэтому сам матч не зависит от серверов Valve. Состояние матча кастомка сама отправляет в худ, наблюдатель с GSI не нужен.

Что кастомка добавляет к стандартной игре:

| | |
|---|---|
| **Экран подготовки** | Выбор команд, кнопка «Я капитан», кнопки хоста: первый выбор, «Раскидать по командам», «Начать драфт», «Без драфта (All Pick)». |
| **Драфт Captains Mode** | Капитаны по очереди банят и пикают: основное время 30 с, резерв 130 с, если время вышло — случайный герой. Порядок ходов тот же, что в имитаторе худа. Потом идёт обычный выбор героев, где каждому игроку доступны только пики его команды. Кто не успел выбрать, получает оставшегося героя автоматически. |
| **Данные для худа** | Раз в секунду на `http://127.0.0.1:3000/gsi` уходит пакет в формате GSI наблюдателя: игроки, герои, предметы, строения, счёт, Рошан, драфт, победитель. Худ показывает всё как обычно, OpenDota не нужна. |
| **Наблюдатель** | Компьютер трансляции подключается к матчу без героя (см. `OBSERVER_MODE`). |

Всё остальное (крипы, Рошан, руны, башни, предметы, курьеры) работает так же, как в обычной Dota.

---

## Схема

```
ПК трансляции (хост): Dota с -tools → на нём крутится сервер матча
   │   также: сервер худа (start.bat), OBS
   │   Lua кастомки ──HTTP 127.0.0.1:3000/gsi──► худ ──► оверлей
   ▲
   └── 10 ПК игроков: connect <IP хоста>   (одна подсеть)
```

---

## Установка (один раз на каждом ПК)

1. Steam → Библиотека → Dota 2 → Свойства → **DLC** → включите **Dota 2 Workshop Tools DLC**.
2. Запустите `install.bat`. Он найдёт Dota и скопирует кастомку в `dota 2 beta\game\dota_addons\arena5v5` и `dota 2 beta\content\dota_addons\arena5v5`.
   Если Dota стоит в другой библиотеке: `install.bat "D:\SteamLibrary\steamapps\common\dota 2 beta"`.
3. **Только на хосте:** в брандмауэре Windows разрешите входящие подключения для Dota (UDP 27015). Обычно Windows сама спрашивает об этом при первом запуске сервера.

Настройки находятся в `scripts\vscripts\arena\config.lua`: адрес и токен худа, режим драфта, время стадий, режим наблюдателя. После правки снова запустите `install.bat` или поменяйте файл прямо в папке Dota.

---

## Запуск матча

1. На хосте запустите сервер худа (`start.bat`) и OBS.
2. На хосте запустите `host.bat`. Dota откроется в режиме Workshop Tools.
3. В консоли Dota (клавиша `~` или `\`) введите:
   ```
   dota_launch_custom_game arena5v5 dota
   ```
   В консоли должны появиться строки:
   ```
   [Arena] Arena 5x5 запускается, режим драфта: cm ...
   [Arena] худ принял первый пакет — связь есть
   ```
4. Игроки запускают `player.bat 192.168.x.x`, где указан IP хоста (`host.bat` выводит его при запуске).
5. На экране подготовки игроки выбирают команды, капитаны жмут «Я капитан», хост нажимает **«Начать драфт»**.
   Хост может ходить за команду без капитана, так удобно репетировать в одиночку.
6. После драфта идёт выбор героев, затем матч. Худ работает как обычно.

## Что проверить на первой репетиции

Код кастомки я проверил на заглушках. Само поведение Dota в режиме Workshop Tools по сети нужно проверить на ваших компьютерах. Проверяйте по шагам, каждый следующий опирается на предыдущий.

| # | Проверка | Если не работает |
|---|---|---|
| 1 | Один ПК: `dota_launch_custom_game arena5v5 dota` → появился экран «Выбор команд». | В консоли будут ошибки Lua или Panorama, пришлите их. |
| 2 | В консоли есть «худ принял первый пакет», на пульте худа идут данные. | «код 0» — неверный `HUD_URL` или не запущен сервер. «403» — `HUD_TOKEN` не совпадает с `token` в `config/server.json`. «CreateHTTPRequestScriptVM вернул nil» — HTTP из скриптов закрыт, нужен обходной вариант. |
| 3 | Второй ПК подключился через `connect IP`. | Брандмауэр на хосте; оба ПК в одной подсети. Если подключение есть, но нет экрана драфта, добавьте `-tools` в `player.bat`. |
| 4 | Драфт: баны и пики видны у всех, худ показывает драфт. | |
| 5 | Выбор героев: в списке только пики своей команды. | Если доступны все герои, через 3 с до конца выбора скрипт сам раздаст правильных героев (это видно в консоли). |
| 6 | Наблюдатель «Без команды» после старта видит матч как зритель. | Поставьте `OBSERVER_MODE = "team"`. Появится команда «Наблюдатели» со скрытым героем и обзором всей карты. |
| 7 | Конец карты: худ сам показывает итоги. | |

Проверить худ без Dota можно так: из папки худа запустите `node dota-addon/arena5v5/test/send-sample.js` (с `--end` для конца карты).

## Изменения в сервере худа

- Пакеты с `provider.custom` принимаются как основной источник. Пока они идут, пакеты обычного клиента Dota с GSI игнорируются, чтобы данные не перемешались. Конфиг GSI на ПК трансляции можно не удалять.
- Для матчей кастомки не запрашивается OpenDota: там их нет, а вся статистика и так приходит из игры.
